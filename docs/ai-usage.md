# AI usage

AI helped with documentation, logging, application code, and tests.

## Example prompts

These are sample prompts, not a record of the prompts used during development.

- Write a short README with the tools needed, build commands, and run commands. Keep the wording simple.
- Summarize the import rules in a few bullet points.
- Check the setup instructions for missing steps and repeated explanations.
- Help me log each source import with its result and record counts.
- Suggest a short error message for a failed source request. Keep exception details in the server log.
- Check that logs help identify failed imports without showing card details.
